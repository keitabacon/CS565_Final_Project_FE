# CS565 Final Project Frontend

This Blazor app uses MudBlazor to display tournament teams, schedules, venues, and information.

## Run locally

1. Install the .NET 11 SDK and confirm it appears in `dotnet --list-sdks`.
2. Open a terminal in the repository root and run:

   ```sh
   dotnet run --project BlazorApp1/BlazorApp1.csproj --launch-profile http
   ```

3. Open [http://localhost:5015](http://localhost:5015).

The first run restores NuGet packages and builds the app. Press **Ctrl+C** in the terminal to stop it.
